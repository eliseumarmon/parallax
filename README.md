# Parallax — Monasterio de Santa María de la Valldigna

Página web dedicada al **Real Monasterio de Santa María de la Valldigna**, desarrollada con HTML y CSS para experimentar con el efecto *parallax* y la presentación de contenido mediante imágenes de fondo.

La página propone un recorrido visual por distintos espacios del monasterio, combinando fotografías y textos informativos.

## Ver el proyecto

**[Visitar la web en GitHub Pages](https://eliseumarmon.github.io/parallax/)**

## Características

- Efecto parallax mediante `background-attachment: fixed`.
- Secciones dedicadas al Portal Nou, la iglesia, el claustro, el refectorio, la Font dels Tritons y la sala capitular.
- Composición de fotografías y bloques de contenido.
- Maquetación y estilos realizados con CSS.

## Tecnologías

- **HTML5:** estructura y contenido.
- **CSS3:** diseño visual, posicionamiento y efecto parallax.

No utiliza JavaScript ni necesita un backend.

## Estructura

```text
├── css/
│   └── styles.css
├── img/
├── content.md
└── index.html
```

`content.md` contiene los textos informativos, mientras que `index.html` y `styles.css` implementan su presentación.

## Contexto

Práctica de diseño web centrada en el uso de imágenes, fondos fijos, posicionamiento y efectos visuales mediante CSS.
